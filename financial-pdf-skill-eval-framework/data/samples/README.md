# Samples

Drop real financial PDFs here. The framework does not ship sample PDFs because
they belong to the evaluation project, not the Skill package.

For convenience the example PDFs `byd_caibao-123-124.pdf` and `华电光大.pdf`
live one level up (`../../byd_caibao-123-124.pdf`); copy or symlink them here
if you want YAML cases under `data/samples/` to resolve.

This directory is intentionally not auto-populated.
