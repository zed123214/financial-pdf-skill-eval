## normalize_number

Rules:

1. Remove commas.
2. Remove ordinary spaces and Chinese spaces.
3. Preserve decimals.
4. `(18,970,274.67)` -> `-18970274.67`.
5. `（18,970,274.67）` -> `-18970274.67`.
6. `-` is empty.
7. Empty string is empty.
8. Never drop decimal points.
9. Never convert parenthesized negatives to positives.
